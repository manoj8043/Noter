# ✨ Noter — Modern Animated Web Application

Noter is a modern, performance-focused web application built with a strong emphasis on **clean UI**, **smooth animations**, and **seamless user experience**.  
The project follows industry-standard practices for security, scalability, and deployment.

This repository demonstrates practical frontend skills, structured code, and real-world deployment readiness.
